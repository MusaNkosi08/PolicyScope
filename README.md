# PolicyScope

A legislative impact simulator. Paste a bill, regulation, corporate policy or contract and get a structured, non-partisan **Impact Dossier** generated by Claude.

**Stack:** React 19 + Vite + TypeScript + Tailwind CSS (no UI library). The API runs as a Vercel serverless function, with an Express server for local dev and self-hosting.

## Quick start

```bash
npm install
cp .env.example .env        # then add your ANTHROPIC_API_KEY
npm run dev                 # web on :5173, API on :8787 (proxied at /api)
```

Open http://localhost:5173 and click **Try a sample bill**.

## Scripts

| Script | What it does |
| --- | --- |
| `npm run dev` | Vite + Express API together (hot reload on both) |
| `npm run build` | Typecheck client and server, then build to `dist/` |
| `npm start` | Express serves `dist/` and `/api/analyze` (self-hosting) |
| `npm run typecheck` | Typecheck only |

## Deploying to Vercel

1. Import the repo in Vercel (framework preset: Vite).
2. Add `ANTHROPIC_API_KEY` under Project → Settings → Environment Variables. Optionally set `ANTHROPIC_MODEL`.
3. Deploy. `api/analyze.ts` becomes `POST /api/analyze` with a 60s max duration (see `vercel.json`).

## Environment variables

| Name | Required | Default |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | yes | none |
| `ANTHROPIC_MODEL` | no | `claude-sonnet-5-5` |
| `API_PORT` | no | `8787` (local Express only) |

The key is read only on the server. Never prefix it with `VITE_`, which would bundle it into the browser.

## How the API handles bad output

1. The reply's outermost `{...}` is extracted (tolerates stray fences or prose) and parsed.
2. It's validated with Zod. Enum values are normalised (`"Medium"` → `"medium"`, `"corporate policy"` → `"corporate_policy"`), a numeric `year` becomes a string, and missing arrays default to `[]`.
3. If validation fails, Claude is asked once to correct its output, with the specific schema errors.
4. If it still fails, or the reply hit the 4096-token limit, the client gets a clear error with a code (`invalid_output`, `output_truncated`) and a retry button.

Upstream errors map to friendly codes: `rate_limited` (429), `upstream_overloaded` (503), `upstream_timeout` (504), `server_misconfigured` (bad key or model).

## Motion and accessibility

- 3px gradient scroll-progress bar, rAF-throttled.
- Reveal-on-scroll via IntersectionObserver (opacity 0→1, translateY 28px→0, 0.7s cubic-bezier, once only).
- Staggered grid children in 0.1s steps via `nth-child` transition delays.
- Parallax for any element with `data-speed` (positive lags the scroll, negative leads), using `translate3d`.
- `prefers-reduced-motion: reduce` turns off all of it: animations, transitions, parallax, the floating logo and the progress bar. Content shows statically.
- Collapsible sections use `aria-expanded`/`aria-controls`, and collapsed content is `inert`. Includes a skip link, visible focus rings and live regions for loading and results.

## Notes

- The dossier is AI-generated. The UI labels precedent confidence and reminds users to check quotes and precedent against primary sources.
- The Express rate limiter is in-memory (10 requests per IP per minute). On Vercel, use Vercel's firewall rate limiting or a KV-backed limiter if you need limits across instances.
